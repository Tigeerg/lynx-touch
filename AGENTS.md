# Agents

Правила для любого ИИ-агента, работающего в этом репозитории. Читай эти файлы до правки кода:

* [CLAUDE.md](CLAUDE.md) — свод стандартов проекта (роль `PROJECT_STANDARDS.md`): язык кода и текстов,
  архитектура и модульность, типизация, обработка ошибок, проверки, поведение панели. Код — на C/C++
  (и существующих TS/QML), **Python не пишут**.
* [AI_WORKFLOW.md](AI_WORKFLOW.md) — роли агентов (Продуктовый менеджер, Архитектор, Исполнитель,
  Специалист по UI, Интегратор, Тестировщик, Ревьюер, Технолог ЧПУ), цикл задачи (TDD), ворота приёмки и
  протокол взаимодействия.
* [ROLES.md](ROLES.md) — короткая шпаргалка для распорядителя: кто есть кто, кого звать под задачу, что
  должно быть готово.
* [`.opencode/skills/`](.opencode/skills/) — ролевые скилы (`product-manager`, `architect`, `coder`,
  `ui-specialist`, `integrator`, `tester`, `reviewer`, `cnc-domain-expert`) и тематические чек-листы
  (`panel-ui`, `viewer-cpp`); скил загружают по точному id.
* [VERSIONING.md](VERSIONING.md) — порядок внесения изменения и ведения версий.
* [ARCHITECTURE.md](ARCHITECTURE.md) — карта модулей и слоёв продукта.
* [TODO.md](TODO.md) — технический долг.

Правила действуют для каждого агента, как бы он ни назывался.

Любое изменение кода и архитектуры требует обновления затронутой документации, журналов и версий в том же
коммите: коммита «код сейчас, документацию допишу потом» не бывает.
