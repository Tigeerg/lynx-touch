# Agents

Правила для любого ИИ-агента, работающего в этом репозитории, — в [CLAUDE.md](CLAUDE.md): на каком языке
пишутся комментарии и тексты интерфейса, как устроены проверки, код и поведение панели. Порядок внесения
изменения и ведения версий — в [VERSIONING.md](VERSIONING.md). Читай оба файла до правки кода. Правила
действуют для каждого агента, как бы он ни назывался.
