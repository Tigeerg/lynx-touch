# Стратегия симуляции съёма материала: 5 методов

Этот документ содержит описание пяти подходов к реализации симуляции съёма материала для проекта `gcode-viewer`. Каждый метод решает свой набор задач, балансируя между скоростью, точностью и поддержкой сложных форм.

---

## 1. Карта высот (Height Map)
*Классический подход для простых задач.*

*   **Принцип:** «Вид сверху». Пространство представлено как 2D-сетка. В каждой точке (X, Y) хранится значение Z (глубина прохода). Съём вычисляется как `Z_новое = min(Z_старое, Z_инструмента)`.
*   **Плюсы:** Молниеносная скорость, минимальные требования к памяти, простота отладки.
*   **Минусы:** Невозможно выразить поднутрения (инструмент шире вверху, чем внизу), сложность обработки по 5 осям.
*   **Применение:** Базовая 2.5D-фрезеровка, черновая обработка.

## 2. Объёмное поле (SDF — Signed Distance Function)
*Математически точный подход.*

*   **Принцип:** Деталь описывается функцией `f(x, y, z)`, которая возвращает расстояние до ближайшей границы. Если `f > 0` — внутри детали, `f < 0` — пустота.
*   **Плюсы:** Математическая точность, поддержка любых форм и булевых операций (вычитание инструмента).
*   **Минусы:** Высокая нагрузка на процессор (требует мощного железа для расчётов).
*   **Применение:** «Оракул точности» для проверки сложных инженерных изделий и контроля зареза.

## 3. Хроника реза (Time-field)
*Метод управления историей процесса.*

*   **Принцип:** К каждому элементу поля добавляется метка времени (`t_рез`), когда он был удален.
*   **Плюсы:** Мгновенная перемотка процесса назад/вперед без пересчёта (O(1)), возможность проигрывания съёма в реальном времени.
*   **Минусы:** Требует дополнительной памяти для хранения времени для каждой ячейки.
*   **Применение:** Удобство оператора, интерактивная отладка УП, визуализация процесса.

## 4. SDF-Воксели (VDB / Octree)
*Структурный подход для сложных форм.*

*   **Принцип:** Пространство разбито на «умные» воксели. Используются разреженные структуры (Octree/VDB), где хранятся только данные вблизи границ (узкая полоса).
*   **Плюсы:** Идеальная гладкость поверхностей, поддержка пустот и переходов, высокая гибкость.
*   **Минусы:** Сложность реализации (структуры данных разреженных деревьев).
*   **Применение:** Работа со сложной резьбой, лабиринтами и деталями, где критично качество поверхности.

## 5. Трассировка лучей (Ray Marching)
*Прямая визуализация в шейдере.*

*   **Принцип:** Мы не строим сетку заранее. При отрисовке каждого пикселя на экране «стреляем» лучом в сцену. В шейдере видеокарты луч делает шаги в зависимости от значения SDF, «летя» к поверхности.
*   **Плюсы:** Безупречное визуальное качество (идеально гладкие кривые), отсутствие «зубчиков» и сеток, высокая реалистичность.
*   **Минусы:** Полная нагрузка на GPU, требует написания сложных шейдеров.
*   **Применение:** Высококачественный предпросмотр, работа на любом железе без сеточных артефактов.
