# Планы и исследования

Каталог для планов, исследований и оценок — документов о намеченной работе, а не о
сделанном. Источник истины о поведении — код и его прогон; здесь только замысел с
числами и оговорками.

Правила, из которых заведён этот каталог (см. `VERSIONING.md`, раздел 2):

- ветки существуют только под опыты с кодом (альтернативные математические методы,
  пробы функциональности); планы и исследования в ветке не держат;
- планы, исследования и оценки живут в `main`, в этом каталоге;
- версия опытной ветки — `<база>+<тег>.<n>`, где `<база>` — версия `main`, на которой
  ветка построена, а `<тег>` называет саму ветку (`sim`, `mesh`, `csg`); так версия
  ветки отличима от версии `main` и вливание однозначно.

## Документы

| Документ | О чём | Ветка / этап |
|---|---|---|
| `HANDOVER.md` | Оперативная передача по работам съёма: правила, ветки и их версии, измеренные факты, открытые пункты с числами, рецепты прогона и уроки. Правится по месту, стареет быстро | `main`, передача новой ветви работ; читать первым, начиная новую ветвь |
| `PLAN-STOCK.md` / `.en.md` | Единый план симуляции съёма: обзор пяти подходов, оценка по числам (что берём и что нет) и четыре детальных плана (карта высот, неявная объёмная модель, поле и время, экранное CSG), сводное сравнение и приёмка | `main`, свод прежних `PLAN-INDEX`/`PLAN-5-METHODS`/`PLAN-STOCK-*` |
| `PORT-CPP.md` / `.en.md` | Запись выполненного переноса бэкенда вьювера на C++: инвентаризация питоновского слоя, этапы, риски и оптимизации (§11) | `main`, перенос выполнен |
| `PORT-QML.md` / `.en.md` | План переноса панели оператора из React в Qt: инвентаризация расхождений (рабочие места, вкладка «Работа», 8 софт-кеев, экран АВТО, тема «Минимал», сенсорный режим), правила, девять этапов с приёмкой, риски и открытые вопросы | `main`, план переноса панели |
| `IDEAS.md` / `.en.md` | Бэклог продуктовых идей (интерактив по 3D, виброаналитика, look-ahead, КИМ, защита от человеческого фактора) с оценкой сложности и привязкой к слоям проекта | `main`, планирование возможностей |

Английские зеркала (`.en.md`) — тот же источник, а не отдельная редакция: оба варианта
правят одним заходом.
