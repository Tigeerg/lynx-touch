# Планы и исследования

Каталог для планов, исследований и оценок — документов о намеченной работе, а не о
сделанном. Источник истины о поведении — код и его прогон; здесь только замысел с
числами и оговорками.

Правила, из которых заведён этот каталог (см. `VERSIONING.md`, раздел 2):

- ветки существуют только под опыты с кодом (альтернативные математические методы,
  пробы функциональности); планы и исследования в ветке не держат;
- планы, исследования и оценки живут в `main`, в этом каталоге;
- версия опытной ветки — `<база>+<тег>.<n>`, где `<база>` — версия `main`, на которой
  ветка построена, а `<тег>` называет саму ветку (`sim`, `mesh`, `csg`); так версия
  ветки отличима от версии `main` и вливание однозначно.

## Документы

| Документ | О чём | Ветка / этап |
|---|---|---|
| `HANDOVER.md` | Оперативная передача по работам съёма: правила, ветки и их версии, измеренные факты, открытые пункты с числами, рецепты прогона и уроки. Правится по месту, стареет быстро | `main`, передача новой ветви работ; читать первым, начиная новую ветвь |
| `PLAN-INDEX.md` | Итоговый индекс пяти методов съёма: принцип, плюсы, минусы и сводная таблица выбора | `main`, обзор методов |
| `PLAN-5-METHODS.md` | Стратегия пяти методов съёма: карта высот, объёмное поле (SDF), хроника реза, воксели (VDB/Octree), ray marching | `main`, обзор методов |
| `PLAN-STOCK.md` / `PLAN-STOCK.en.md` | План работ по методу 1: карта высот, слоистая поверхность, точная огибающая хода | `main`, варианты 1-2 |
| `PLAN-STOCK-IMPLICIT.md` / `.en.md` | Метод 2: неявная объёмная модель, разреженные блоки узкой полосы, поднутрения | `main`, вариант 2 |
| `PLAN-STOCK-TIMEFIELD.md` / `.en.md` | Метод 3: съём как пространственно-временное поле, хроника реза и перемотка | `main`, вариант 3 |
| `PLAN-STOCK-METHODS.md` / `.en.md` | Оценка вокселя и других объёмных методов по числам: что берём, что не берём и почему | ветка `docs/stock-simulation-plans` (перенесён в `main/docs/`), задача точной границы реза |
| `PLAN-STOCK-CSG.md` / `.en.md` | Метод 4: экранное CSG заметаемых тел (BVH капсул и конусов, точный луч без шага), граница точна по построению | `main`, резерв ветки `alt/stock-csg` |

правят одним заходом.
