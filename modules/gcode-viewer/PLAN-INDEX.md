# Методы симуляции съёма материала: итоговый индекс

Этот документ объединяет пять подходов к реализации симуляции съёма материала. Каждый метод решает свой набор задач, балансируя между скоростью, точностью и поддержкой сложных форм (поднутрений, многокоординатной обработки).

---

## 1. Карта высот (Height Map)
*Представление: 2D-сетка глубин.*

*   **Принцип:** «Вид сверху». Программа знает только глубину Z для каждой точки XY. Съём — обновление значения `Z_новое = min(Z_старое, Z_инструмента)`.
*   **Плюсы:** Молниеносная скорость, минимальное потребление памяти, простота реализации.
*   **Минусы:** Невозможно выразить поднутрения (инструмент шире вверху, чем внизу), сложность многокоординатной обработки.
*   **Применение:** Рабочая лошадка для простых 2.5D задач.

## 2. Объёмное поле (SDF)
*Представление: Неявная 3D-функция расстояния.*

*   **Принцип:** В каждой точке 3D-пространства хранится расстояние до ближайшей поверхности детали. Поверхность — это место, где расстояние равно 0.
*   **Плюсы:** Точное математическое описание, поддержка сложных форм, идеальная точность булевых операций.
*   **Минусы:** Высокая нагрузка на процессор (требует мощного железа для расчётов на лету).
*   **Применение:** Оракул точности для проверки сложных инженерных изделий.

## 3. Хроника реза (Time-field)
*Представление: Поле с измерением времени.*

*   **Принцип:** На каждый узел заготовки записывается не только глубина, но и время (или `pathDist`), когда узел был срезан.
*   **Плюсы:** Мгновенная перемотка истории назад без пересчёта всей программы (O(1)).
*   **Минусы:** Дополнительные затраты памяти (храним `time` рядом с `depth`).
*   **Применение:** Интерактивное управление, визуализация процесса во времени, отладка УП.

## 4. SDF-Воксели (VDB / Octree)
*Представление: Разреженные блоки со значениями SDF.*

*   **Принцип:** Пространство разбито на «умные» кубики (воксели). Там, где пусто или сплошной металл, ничего не хранится. У поверхности кубики хранят значения SDF.
*   **Плюсы:** Идеальная гладкость, поддержка любых пустот и переходов, высокая гибкость через использование разреженных деревьев (VDB).
*   **Минусы:** Сложность реализации структуры данных (Octree/VDB).
*   **Применение:** Работа со сложной резьбой, лабиринтами и деталями, где критично качество поверхности.

## 5. Трассировка лучей (Ray Marching)
*Представление: Вычисление «на лету» в шейдере.*

*   **Принцип:** Мы не строим геометрию заранее. При отрисовке каждого пикселя мы «стреляем» лучом и ищем поверхность прямо в шейдере видеокарты, ориентируясь на SDF.
*   **Плюсы:** Безупречное качество, отсутствие «зубчиков» и сеток, высочайшая визуальная реалистичность.
*   **Минусы:** Полностью ложится на GPU, требует написания продвинутых шейдеров.
*   **Применение:** Визуализация высокого качества, где важна идеальная картинка без сеток.
